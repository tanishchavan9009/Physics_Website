## 🌌 Overview

**Quantum Physics — Engineering Physics** is a high-performance, responsive visual web platform designed to make abstract quantum mechanical concepts intuitive, engaging, and hands-on. 

Featuring custom particle canvasses, neon-glow visual styling, real-time physics simulations, formula reference sheets, an interactive timeline of quantum pioneers, and an interactive quiz assessment engine.

---

## ✨ Features

- 💫 **Interactive Particle Hero:** Dynamic interactive canvas reacting in real-time to cursor movements and wave mechanics.
- 🔬 **Real-Time Physics Simulations:** Explore wave-particle duality, probability density functions, and quantum phenomena visually.
- 📐 **Quantum Formula Deck:** Comprehensive formula guide complete with KaTeX math rendering, explanations, and unit definitions.
- ⏳ **Chronology of Discovery:** Interactive historical timeline highlighting breakthroughs from Planck, Einstein, Bohr, de Broglie, Heisenberg, Schrödinger, and Dirac.
- 🧠 **Interactive Knowledge Check:** Dynamic quiz engine with instant score calculation and deep-dive answer rationales.
- 🎛️ **Zero-Friction Fullscreen Mode:** Embedded cleanly into Streamlit with custom viewport styling and seamless scrolling.

## 🧪 Interactive Simulations

| Simulation | Concept Explored | Key Variable Controls |
| :--- | :--- | :--- |
| **🌊 Double Slit Experiment** | Wave interference vs. particle detection | Wavelength ($\lambda$), Slit distance ($d$), Screen distance ($D$) |
| **📦 Particle in a 1D Box** | Quantized energy levels & standing wavefunctions | Quantum number ($n$), Box width ($L$) |
| **💡 Photoelectric Effect** | Photon energy, work function, and stopping potential | Frequency ($\nu$), Metal threshold ($\Phi$), Intensity |
| **🌀 Heisenberg Uncertainty** | Wave packet dispersion and localization trade-off | Position uncertainty ($\Delta x$), Momentum ($\Delta p$) |

## 📐 Core Quantum Formulations

$$E = h\nu = \hbar\omega$$

$$\lambda = \frac{h}{p} = \frac{h}{mv}$$

$$i\hbar\frac{\partial}{\partial t}\Psi(\mathbf{r}, t) = \hat{H}\Psi(\mathbf{r}, t)$$

$$\Delta x \cdot \Delta p \geq \frac{\hbar}{2}$$

## ⚡ Quick Start

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/tanishchavan9009/physicswebsite.git
cd physicswebsite
```

### 2️⃣ Install Dependencies
Ensure you have Python 3.8+ installed:
```bash
pip install -r requirements.txt
```

### 3️⃣ Launch the App
```bash
streamlit run streamlit_app.py
```
Your default browser will automatically open: `http://localhost:8501`
